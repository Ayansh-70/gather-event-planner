# Prompt Wars submission

Repository: **https://github.com/Ayansh-70/gather-event-planner**  
Vertical: **Event planning — weddings, birthdays and community events**  
Project: **Gather**

## Suggested three-minute demonstration

1. Start on the overview. Explain the calm, task-focused workspace and local privacy model.
2. Create a birthday for 30 guests with a fixed budget and a date a week away. Point out the compressed checklist and exact budget allocations.
3. Increase an actual payment above a category allocation. Show the category balance and overall budget totals.
4. Add a venue candidate, check written terms and mark it booked. Explain why quotes and payments are separate.
5. Enter vegetarian food, step-free access and a favorite theme in the brief. With a working Gemini key, generate ideas and ask a personalized question. Without one, explicitly identify the local guide as rule-based and explain the genuine provider integration.
6. Save an idea, complete a task and export the plan. Show the tests and README.

## Evaluation mapping

| Focus | Evidence |
| --- | --- |
| Code quality — high | Domain logic separated from persistence, presentation and API adapter; readable formatted source; small dependency-free runtime; documented architecture |
| Problem alignment — high | Three event personas; budget, timeline, vendors, ideas and context-aware AI; practical updates and portability |
| Security — medium | Server-side key, bounded input/output, strict CSP, escaped text, same-origin checks, rate limits, optional AI access code |
| Efficiency — medium | No production dependencies or build step; original tiny SVG assets; local calculations; bounded context and provider calls only on request |
| Testing — low | Domain, HTTP, mocked Gemini and DOM interaction tests; CI; explicit manual checklist and verification limitations |
| Accessibility — low | Semantic controls, labels, keyboard focus, skip link, native dialogs, status announcements, reduced motion, responsive layout |
